# 台海動態羅盤 Strait Watch Compass

一個用於紀錄與分析中共對台灰色地帶軍事活動（如軍機、潛艦、共艦、無人機、氣球及漁船）的本地日誌與數據可視化工具。

---

## 功能特點

1. **紀錄事件 (Record)**: 快速登錄共軍海空活動的日期、類型、數量、位置航線、備註及資料來源。
2. **分類篩選 (Categorize)**: 支援以類型、起訖時間、數量或日期順序，對歷史紀錄進行多欄位篩選與排序。
3. **數據分析 (Analyze)**:
   - 包含 **活動數量趨勢** (架次/艘次/累加數量) 與 **活動次數趨勢** (偵獲次數/事件筆數) 兩張獨立的折線圖。
   - **雙 Y 軸支援 (Dual Y-Axis)**: 左軸 ($y_1$) 對應數量較高的軍機與艦艇；右軸 ($y_2$) 具備獨立 Scale，專門展示數量較少但極具預警價值的**無人機**、**公務與民用船**及**空飄氣球**，避免曲線被壓平。
   - 支援切換 **日 (Day)**、**週 (Week)**、**月 (Month)**、**年 (Year)** 四種 X 軸時間維度。
   - 提供專屬的時間範圍過濾，方便將分析視角聚焦於特定的時間區間。
   - 具備深/淺色主題，折線圖色彩與文字能自動自我調整。
4. **報告與備份 (Report)**: 一鍵將所有資料產出為 Markdown 格式的摘要報告，亦可下載 JSON 作為備份，或將備份 JSON 重新匯入本系統。

## 爬蟲資料更新與同步說明

右上角的 **「同步爬蟲資料」** 按鍵採用 **差額比對** 邏輯。只有在偵測到您的瀏覽器暫存（`localStorage`）中，有少於本地 `records.js` 所記載的紀錄時，按鍵才會主動顯示；若資料已是最新且完全一致，按鍵將自動隱藏，以防止重複同步。

> [!NOTE]
> **📊 國防部歷史資料結構與 OCR 補齊說明 Data History & OCR Notes**：
> 1. **2024 年全年度 PDF/OCR 自動化補齊**：已透過 `mnd_ocr_pipeline.py` 自動下載 2024 全年（360 天）國防部公告圖檔與 PDF 附件，結合 PyMuPDF 與 RapidOCR 完成文字辨識與結構化提取。2024 全年累計：軍機 5,082 架次、共艦 2,365 艘次（平均每日約 6~7 艘巡弋）、公務船 125 艘次、空飄氣球 70 枚、無人機 44 架次。
> 2. **🎈 空飄氣球解析**：2024 年 1~2 月國防部採多項目條列式發布空飄氣球動態，系統已升級演算法完整提取全整年 70 枚氣球之每日統計。
> 3. **🚢 2022 年 7 月前無「共艦」數據之原因**：國防部於 2020 年 9 月至 2022 年 7 月期間每日僅發布「進入我西南空域空域活動示意圖」（僅統計軍機）。直至 **2022 年 8 月 1 日起**（裴洛西訪台及中共環台演習後），官方正式改版為「臺海周邊海、空域活動」，始納入每日共艦艘次與全台海動態。
> 4. **🛩️ 無人機數據說明**：2025/2026 年的無人機活動並未消失，而是已完全包含在每日「共機（Aircraft）」總架次之中。

### 如何抓取與每日更新國防部最新即時資料？

由於國防部官網有跨網域存取限制（CORS），網頁需透過本地 Python 爬蟲腳本取得最新動態。我們提供以下三種更新方式：

#### 方案一：一鍵雙擊更新（推薦最方便）
1. 雙擊執行專案目錄下的 **`更新最新動態.bat`** 捷徑。
2. 腳本會自動在 3~5 秒內向國防部抓取最新動態並更新 `records.js`，隨後**自動開啟**台海動態羅盤網頁。
3. 進入網頁後，右上角會自動顯現 **`🔄 同步爬蟲資料`** 按鍵，點擊即可一鍵將最新資料同步進瀏覽器中！

#### 方案二：Windows 工作排程器每日自動更新（完全自動化）
若希望**完全不需要手動點擊**，可設定 Windows 工作排程器：
1. 按下 `Win + R` 輸入 `taskschd.msc` 開啟工作排程器。
2. 建立基本工作，名稱設為「共軍動態每日更新」。
3. 觸發程序設為「每日」（例如每天早上 09:00 或中午 12:00）。
4. 動作選擇「啟動程式」，程式填入 `python.exe` 的完整路徑，引數填入 `mnd_scraper.py 5`，起始於填入本專案目錄路徑。
5. 設定完成後，每日背景將自動抓取最新資料，您打開網頁點擊同步即可。

#### 方案三：手動執行 Python 指令
在專案根目錄下開啟終端機執行：
```bash
python mnd_scraper.py 5
```
*註：`5` 代表僅抓取最新 5 頁公告；若欲全量更新，可改為 `all` 或省略該參數（預設抓取 230 頁）。*

## 快速測試與示範

1. 點擊網頁左側羅盤中心的 **「說明 (Help)」** 切換至說明頁面。
2. 點擊 **「載入現代範例資料」** 或 **「載入 1995-1996 飛彈危機數據」** 可立刻產生範例資料，並自動切換至「分析」頁面檢視圖表。
3. 若要清空資料以重新測試同步，可至 **「報告 (Report)」** 頁面點選紅色的 **「清空所有紀錄」** 即可。所有資料均存在您本地瀏覽器快取中，不會上傳至任何雲端伺服器。
